# Claude Code workspace rules

Purpose: complete the assigned task with verifiable output and minimal changes. This repository contains only reusable, non-confidential templates until private access is confirmed.

1. Start by reading README.md and the active task specification.
2. Identify files to change and define acceptance checks before editing.
3. Prefer the smallest implementation that satisfies the task.
4. Do not invent source verification, test results, costs or completed actions.
5. Distinguish observed evidence from model-generated interpretation.
6. Run deterministic local checks before using paid API calls.
7. Stop on critical security, privacy, scientific-integrity or patient-safety issues.
8. Never commit credentials, patient records, unpublished manuscripts or other confidential data.
9. Never deploy, publish, purchase, send data externally or change permissions without explicit approval.
10. Report changed files, executed tests, unresolved risks and exact next step using templates/handoff.md.
11. If quality requirements are met, avoid unnecessary revisions.
12. Use .claude/skills/quality-gate/SKILL.md when reviewing deliverables.
