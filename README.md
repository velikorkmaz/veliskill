# veliskill

Reusable instructions and quality checks for a human-supervised AI production workflow.

## Scope
- Project instructions for Claude Code and other coding assistants
- Reproducible quality checks and task handoffs
- Source control for configuration, templates and code only

## Privacy
This repository may be public. Never commit private project plans, unpublished manuscripts, patient data, research records, financial information, API keys, tokens or confidential documents here. Moving this repository to **Private** is required before using it for internal project management. Private repositories still require careful handling of sensitive data.

## Getting started
1. Read `CLAUDE.md`.
2. Copy `templates/task.md` for the work item.
3. Run the checks described in `.claude/skills/quality-gate/SKILL.md`.
4. Record a handoff using `templates/handoff.md`.

No workflow here authorizes automated publication, payment, external sharing, or processing of personal health information.
